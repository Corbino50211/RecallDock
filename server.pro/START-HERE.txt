RECALLDOCK — ONE UPLOAD, ONE START COMMAND

1. STOP your Server.pro app.
2. Upload EVERYTHING INSIDE this server.pro folder into your app folder.
   Include the public folder. Keep your existing data folder and settings.json
   if you already installed RecallDock. Do not delete your existing files.
3. Set Start Command to server.js and press START.
4. In the console, find:
      OPEN YOUR WEBSITE: https://...
      SETUP CODE: ...
   Open that website link. Click Create an account and use the setup code.

DONE. The website, accounts and memories are all on this Server.pro app.
No GitHub Pages setup. No database installation. No terminal commands.
No memory-server URL to type into the website.

You need Node.js 24 or newer. Port defaults to 300. Only change the port
in settings.json if Server.pro allocated a different one. A panel PORT
environment variable takes precedence.

Already installed? Upload the new server.js, backend.js, tunnel.js,
package.json and entire public folder. KEEP data/ and settings.json.
The data folder holds your existing accounts and memories.

HTTPS is started automatically through Cloudflare. The first start downloads
and verifies the helper. Your host must allow downloading/running it and
outbound TCP port 7844. The helper stays cached in bin/ for later starts.
If the tunnel fails, send the console error. The website is also served on
the app's allocated HTTP port, but HTTP does not encrypt login details.
Use the HTTPS link for your account.

The temporary HTTPS link can change when the server restarts. Use the latest
OPEN YOUR WEBSITE link (also stored in data/https-url.txt). Your saved data
stays on the server. A permanent domain needs a separately configured named
tunnel; the temporary link needs no domain or Cloudflare account.

The setup code is also in data/invite-code.txt. Keep it private. It is used
for creating accounts, not for signing in to accounts you already created.
Stop the app before backing up the complete data folder.

CONNECT CLAUDE CODE
After signing in, open Devices & setup. Generate a key for each computer
and follow the plugin setup instructions. Use this website's HTTPS URL in
the plugin's setup prompt. If the temporary URL changes, rerun plugin setup.
