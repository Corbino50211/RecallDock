A TWO-MINUTE SETUP

Bring your context along.

  1. Install Node.js 24+ and download this project's source.
  2. In its folder, run node plugin/scripts/recall.mjs setup
  3. Enter your memory server's HTTPS address and your device key in the local terminal.
  4. Inside your project, run node /path/to/plugin/scripts/recall.mjs project my-project
  5. Launch claude --plugin-dir /path/to/plugin
